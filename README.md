# RPG Quest V2

A modern, open-source endless RPG web game built with React, Vite, and Tailwind CSS.
Battles, loot, levels, and epic bosses await!

## 🌍 English

### 🚀 Getting Started

To run this game locally on your machine, follow these steps:

#### Prerequisites
- Node.js installed (LTS version recommended)
- Git (optional, for cloning)

#### Installation
1. Clone the repository or download the ZIP file:
   ```bash
   git clone https://github.com/achiyama30/RGP.git
   ```
2. Navigate to the project directory:
   ```bash
   cd RGP
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

> [!NOTE]
> **Windows/PowerShell Users:** If you receive an error stating `npm.ps1 cannot be loaded because running scripts is disabled`, run the following command in PowerShell as Administrator, and then try `npm install` again:
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
> ```

4. Start the development server:
   ```bash
   npm run dev
   ```
5. Click the link provided in your terminal (usually `http://localhost:5173`) to play the game!

### 🛠️ Tech Stack
- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React

### 🚀 איך מתחילים

כדי להריץ את המשחק במחשב המקומי שלך, עקוב אחר השלבים הבאים:

#### דרישות מקדימות
- מותקן Node.js (מומלצת גרסת ה-LTS)
- Git (אופציונלי, לצורך הורדת הקוד)

#### התקנה
1. הורד את הקוד או בצע Clone למאגר:
   ```bash
   git clone https://github.com/achiyama30/RGP.git
   ```
2. נווט לתיקיית הפרויקט:
   ```bash
   cd RGP
   ```
3. התקן את הספריות הנדרשות:
   ```bash
   npm install
   ```

> [!NOTE]
> **למשתמשי ווינדוס / PowerShell:** אם אתם מקבלים שגיאה שמודיעה ש-`cannot be loaded because running scripts is disabled` בעת הרצת פקודת npm, הריצו את הפקודה הבאה ב-PowerShell, ואז נסו שוב:
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
> ```

4. הפעל את שרת הפיתוח של המשחק:
   ```bash
   npm run dev
   ```
5. לחץ על הקישור שיופיע בטרמינל (לרוב `http://localhost:5173`) כדי לשחק!
